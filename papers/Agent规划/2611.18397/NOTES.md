# Gamer: A Generalist Vision-Language-Action Foundation Model for Long-Horizon Real-Time Game Agent

> 我们介绍Gamer，这是一个通用的智能体框架，专为复杂交互环境中的长期任务而构建。它的端到端架构结合了感知、记忆管理和多步骤推理。一个共享的训练和部署管道支持与传统的2D图形界面和复杂的3D模拟世界的交互。我们首先在由数万小时的设备级键盘和鼠标交互构建的数据集上继续预训练。这些轨迹跨越模拟游戏和具体化环境，允许模型跨物理和虚拟领域学习环境动态。稀疏思维指令微调然后大大减少冗余计算，同时保留复杂决策所需的推理。
我们使用稳定的多圈强化学习方法来训练长期交互的策略，该方法解决了有限的上下文窗口，累积的推出错误和稀疏的奖励。对于实时交互，云边缘推理引擎同时服务于众多模拟游戏环境，支持无界上下文执行，并保持在线推理延迟低。在多个具有挑战性的3D开放世界游戏中，Gamer展示了与熟练玩家相当的坚实泛化能力和操作效率。它还在一系列传统2D游戏基准上取得了具有竞争力的结果。这些结果表明，即使是重复的键盘和鼠标轨迹也可以支持缩放数据和学习算法带来的实质性收益。在这些轨迹上进行训练有助于Gamer在物理和数字属性兼具的环境中更稳定地学习复杂技能。
这种方法为跨数字和物理世界交互的通才代理提供了一条途径。

## Q1: 这篇论文试图解决什么问题？

这篇论文试图解决构建能够在复杂、多样化游戏环境中执行长时程实时任务的通用视觉-语言-动作（VLA）智能体所面临的核心挑战。具体而言，论文针对以下关键问题展开：

- **跨游戏通用控制的缺失**
  现有游戏智能体大多依赖特定游戏的内部状态、定制动作空间或专用 API，导致泛化能力受限，难以跨越不同游戏领域。论文致力于构建一个**非侵入式**的通用智能体框架，仅通过原始屏幕像素观察环境和标准键盘鼠标接口执行动作，从而消除对游戏特定基础设施的依赖，实现对视觉与机制迥异的多种游戏的统一控制。

- **长时程任务中的记忆、推理与误差累积**
  现代 3D 开放世界游戏要求智能体在数小时量级的交互中持续进行战略决策、资源管理和多阶段目标推进。这带来了**有限上下文窗口**、**执行误差随时间累积**以及**稀疏奖励**等难题。论文需要解决如何在长轨迹中维持可靠的任务记忆、进行多步推理，并在关键决策点生成可执行动作。

- **实时交互的延迟瓶颈**
  动态游戏环境在智能体观察、推理和动作期间持续演化。传统推理引擎的高延迟会导致动作到达时游戏状态已发生变化，进而引发控制错误、冗余交互和早期失败。此外，延迟的 rollout 会稀释在线强化学习（RL）中的策略反馈质量，增加 wall-clock 收集时间。论文需要解决如何支持**低延迟的实时推理**，使动作生成与游戏演进同步。

- **规模化数据利用与在线策略优化**
  论文需要建立可扩展的数据构建流程，将海量异构原始游戏轨迹转化为包含任务指令、稀疏推理和记忆摘要的多层级监督数据。同时，需要设计稳定的在线 RL 方法，在实时交互约束下利用可验证的环境反馈优化长时程策略，并配套高效的训练-推理一体化基础设施以支持大规模并发环境交互。

## Q3: 论文如何解决这个问题？

Gamer 通过一套端到端的通用智能体框架解决上述问题，该框架将感知、记忆管理与多步推理整合在统一的自回归策略中，并配套了支持实时交互的训练与推理基础设施。具体解决方案涵盖以下五个层面：

## 1. 统一的非侵入式观察-动作接口

Gamer 摒弃了对游戏内部状态或专用 API 的依赖，建立了一个跨游戏的共享设备级接口：

- **输入**：仅以原始屏幕像素作为观察，辅以控制规格说明 $\mathcal{B} = \{(k_i, d_i)\}_{i=1}^{|\mathcal{B}|}$，其中 $k_i$ 为键盘或鼠标按键，$d_i$ 描述其在当前游戏中的逻辑功能。
- **输出**：采用统一的键盘-鼠标动作序列化格式。在每个 200 ms 的观察间隔内，策略预测累积鼠标位移 $\Delta P_t$ 与六个细粒度按键块 $K_{t,1}, \dots, K_{t,6}$：
  $$
  a_t = (\Delta P_t; K_{t,1}, \dots, K_{t,6})
  $$
  该表示以 30 Hz 的底层控制频率支持按键持续、短触、拖拽及组合输入，且直接复用预训练语言模型的输出词表，无需额外的动作头。

## 2. 三阶段可扩展训练范式

### 2.1 跨游戏持续预训练（CPT）

为建立可迁移的控制先验，Gamer 在数万小时跨游戏键盘鼠标交互轨迹上继续预训练，并引入两项关键技术减轻数据偏差：

- **随机按键重映射**：对每条轨迹采样随机双射 $\sigma: \mathcal{K}_{\text{bind}} \to \mathcal{K}_{\text{bind}}$，将控制规格与动作中的可重绑定按键同步映射，迫使模型依据按键功能而非固定键位生成动作。
- **重复感知损失衰减**：针对游戏中超过 85% 的动作重复现象，对连续重复动作的 token 损失施加指数衰减权重 $\omega_t = \gamma^{n_t-1}$（$\gamma=0.9$），使监督聚焦于行为转换而非持续状态：
  $$
  \mathcal{L}_{\text{action}} = -\sum_{t=1}^{T} \omega_t \sum_{j=1}^{|a_t|} \log \pi_\theta(a_{t,j} \mid \mathcal{B}, H_t, r_t, a_{t,<j})
  $$

### 2.2 稀疏推理与跨上下文记忆的监督微调（SFT）

CPT 学习的是可迁移控制，SFT 则通过多层次任务监督教授模型遵循显式目标并管理长时程状态：

- **多级任务条件**：指令 $I$ 按时间尺度分为局部操作 $I_{\text{op}}$、中间子目标 $I_{\text{sub}}$ 和完整任务 $I_{\text{task}}$，训练单一策略处理不同粒度的目标。
- **稀疏自适应推理**：策略在每一步首先生成可选推理序列 $r_t \in \{\emptyset, r_t^{\text{cur}}, r_t^{\text{mem}}\}$。常规控制步骤直接输出动作（$r_t = \emptyset$）；在路径修正、目标切换等关键决策点生成当前推理 $r_t^{\text{cur}}$；在上下文边界处生成记忆摘要 $r_t^{\text{mem}}$。
- **基于摘要的跨上下文记忆**：当历史交互 $H_t$ 即将超出上下文预算时，模型将其划分为待丢弃部分 $H_t^{\text{old}}$ 与保留部分 $H_t^{\text{keep}}$，并生成记忆摘要：
  $$
  r_t^{\text{mem}} \sim \pi_\theta(\cdot \mid \mathcal{B}, I, M_t, H_t)
  $$
  更新后的长程记忆与短期历史满足：
  $$
  \langle M_t^+, H_t^+ \rangle = \langle \bar{M}_t \oplus r_t^{\text{mem}}, H_t^{\text{keep}} \rangle
  $$
  这使得任务状态得以在上下文窗口外持久保存，支撑数小时量级的连续交互。

### 2.3 时序感知 GRPO（TA-GRPO）的长时程在线优化

针对长交互超出上下文窗口、执行误差累积及奖励稀疏的问题，Gamer 提出了 Temporal-Aware Group Relative Policy Optimization：

- **记忆链接的 Rollout 分段**：将长轨迹通过记忆压缩机制切分为有限段 $\tau_{g,1}, \dots, \tau_{g,J_g}$，段间通过生成的记忆摘要保持任务状态连贯，无需昂贵的游戏状态恢复。
- **可验证的环境奖励**：利用游戏引擎暴露的任务状态转换与完成条件作为段级评分 $S_{g,m} = R_{g,m}^{\text{env}}$，无需学习过程奖励模型或价值网络。
- **时序信用分配**：在段内对个体决策施加随时间指数衰减的权重，将段级优势 $A_{g,m}$ 按 later-step-closer-to-outcome 的原则重新分配：
  $$
  \tilde{d}_{g,m,t} = \frac{\beta^{T_{g,m}-1-t}}{\frac{1}{T_{g,m}}\sum_{u=0}^{T_{g,m}-1} \beta^{T_{g,m}-1-u}}, \quad A_{g,m,t} = \tilde{d}_{g,m,t} A_{g,m}
  $$
  其中 $\beta \in (0,1)$。目标函数对策略进行 token 级裁剪更新：
  $$
  \mathcal{L}_{\text{TA-GRPO}} = -\frac{1}{\sum_m G_m} \sum_m \sum_{g \in \mathcal{V}_m} \frac{1}{T_{g,m}} \sum_{t=0}^{T_{g,m}-1} \frac{1}{|y_{g,m,t}|} \sum_{j=1}^{|y_{g,m,t}|} \ell_{g,m,t,j}(\theta)
  $$

## 3. 实时推理引擎 Streaming-vLLM

为消除推理延迟导致的动作过时与 RL 偏差，Gamer 开发了 Streaming-vLLM，作为训练、评估与部署的共享后端：

- **有状态流式上下文**：通过分页 KV 缓存管理保留历史状态的缓存页，在记忆压缩后仅对新追加 token 进行预填充，并对保留键值的旋转位置编码（RoPE）进行增量相位刷新，避免重复编码完整上下文。
- **架构感知执行**：针对 Dense 与 MoE 主干（如 Qwen3-VL 与 Qwen3.5 系列）分离通用服务接口与专用计算后端，融合算子、张量并行、通信掩盖与 CUDA Graph，减少解码器启动及设备间通信开销。
- **FSM 引导的投机解码与流式动作分发**：利用有限状态机快速起草结构 token（如 `<think>`、`<|action_start|>` 等），由 BF16 目标模型验证后提交；同时在首个按键块验证通过后即向客户端流式发送，使动作执行与后续 token 生成并行，将端到端延迟从约 1.3 秒降至 65 毫秒（在 H200 上实现 20.1× 加速）。

## 4. 可扩展的长时程数据构建

为将原始录像转化为长时程监督信号，论文建立了基于 GPT-5.6-Luna 的自动标注流水线：

- **动作对齐与过滤**：对约 1K 小时筛选后的轨迹进行动作-观察时间戳对齐，剔除异常输入与长时段空闲。
- **三级自底向上构造**：从短视窗的关键决策点提取稀疏 Think 注解；从长视频片段识别任务段并生成指令与场景描述；从连续视觉上下文生成第一人称记忆摘要。最终构建出覆盖操作级、子目标级与任务级的指令数据，分别训练局部控制、中期规划与长期任务执行能力。

## 5. 统一的训练-评估-部署基础设施

- **扩展 Verl 框架**：在共享框架内支持 CPT、SFT 与 TA-GRPO，使用 Streaming-vLLM 生成交互式评估与在线 RL 的 rollout。
- **自动化沙盒环境**：通过游戏引擎插桩暴露任务状态与完成条件，由 GM 指令控制可复现的任务初始状态；32 个并行 Windows 游戏实例由 64 张 H200 GPU 组成的 sharded 推理池驱动，每轮迭代收集 128 条轨迹，实现大规模实时策略优化与系统化自动测试。

通过上述设计，Gamer 在统一键盘鼠标动作空间内，将跨域轨迹规模化、长时程稀疏推理与记忆、低延迟实时交互及稳定的在线 RL 整合为连贯的通用智能体方案。

## Q4: 论文做了哪些实验？

论文围绕**跨游戏控制扩展规律**、**长时程任务执行**、**多样化小游戏泛化**、**实时交互对在线学习的影响**以及**推理引擎效率**五个维度展开系统性实验，具体如下：

### 1. 持续预训练（CPT）的受控扩展研究（GameScaling）
该研究通过 **120 个受控配置**（4 种模型规模 × 6 个数据预算 × 5 种数据混合比例），系统刻画模型容量、游戏时长与数据组成对 CPT 的影响：

- **界面适应分析**：监测键盘损失、鼠标损失、动作格式损失及方向预测准确率，验证早期 CPT 快速适应共享控制接口。
- **扩展规律拟合**：拟合组合感知扩展公式
  $$L_{\text{val}}(N, D, q) = E + \frac{C_N}{N^a} + \frac{C_D q^\eta}{D^b} + \frac{C_q}{(q+\epsilon)^c}$$
  其中 $N$ 为模型规模，$D$ 为数据时长，$q$ 为目标相关数据占比。该公式在训练损失（$R^2=0.980$）、Minecraft 验证损失（$R^2=0.982$）及训练游戏内验证损失（$R^2=0.995$）上均表现出良好拟合。
- **跨游戏泛化**：在 **MCU**、**ViZDoom**、**OmniGameArena**、**GameWorld** 四个公开基准上评估，区分训练覆盖环境（MCU/ViZDoom）、行为相关未见过环境（OmniGameArena）与较远分布环境（GameWorld），证明多游戏混合训练对行为相关迁移的促进作用，以及对遥远未见游戏的泛化局限。

### 2. CPT 策略的跨游戏实时性能
在四个公开游戏基准上，对比 **Gamer-8B-CPT**（Dense）与 **Gamer-35B-A3B-CPT**（MoE）和 7 个通用多模态基线（GPT-5.6-Sol、Gemini-3.8-Flash、Claude-Opus-5.0 等），并区分**理想暂停（TP）**与**实时（RT）**两种评估模式：

| 关键发现 |
|---------|
| CPT 策略在实时交互下显著超越最强通用基线（8B 平均 29.5%，MoE 平均 31.5%），尤其在 MCU 上分别达到 47.7% 和 65.3%。 |
| MoE CPT 策略在实时评估中相对暂停评估平均提升 +3.4 分，体现低延迟推理对释放 CPT 学习能力的正向作用。 |
| 证明 CPT 方法可同时适用于 Dense 与 MoE 架构，并将验证损失上的扩展趋势转化为可执行的游戏结果。 |

### 3. 长时程指令跟随：支线任务（Side Quests）
在 **Honkai: Star Rail** 的两个保留支线任务上进行评估：
- **Opportunity Makes the Thief (Part I)**：30 个里程碑，22 个父步骤，涵盖导航、对话、战斗、UI 交互。
- **Bestial Ferocity**：55 个里程碑，40 个父步骤，额外包含三个机关修复谜题。

对比 **Qwen3-VL-8B (Base)**、**Gamer-CPT**、**Gamer-SFT**、**Gamer-RL**：

| 模型 | Opportunity Makes the Thief (I) 总体准确率 ↑ | Bestial Ferocity 总体准确率 ↑ |
|------|------------------------------------------|------------------------------|
| Base | 0.0% | 13.9% |

### 5. 实时 Rollout 对在线 RL 的影响
在 8 个导航任务上，对比 **Streaming-vLLM 实时推理**与**标准 vLLM 低帧率（0.6-FPS）控制**的 RL 训练动态：

- **实时设置**：更早出现奖励提升，且在多数任务中达到更高最终奖励。
- **低帧率设置**：多个任务在后期出现奖励崩溃（reward collapse），表明延迟导致的累积执行错误会引入有偏轨迹，破坏训练稳定性。
- 结论：低延迟推理不仅是部署需求，更是复杂商业游戏中有效且稳定在线 RL 的前提。

## Q5: 有什么可以进一步探索的点？

基于论文的局限性讨论与整体技术框架，以下几个方面值得进一步探索：

### 1. 扩展评估环境与任务覆盖范围
当前实验覆盖了选定的 3D 商业游戏与 2D 基准，但通用智能体的能力边界仍需在更广泛的交互环境中验证。未来工作可将联合后训练与系统化评估扩展至更多样化的交互场景，包括：
- 更复杂的任务结构（如多线程并行任务、动态目标优先级调整）；
- 开放世界中的非线性叙事与涌现式玩法；
- 不同物理特性与数字属性的混合环境（如结合实体机器人控制的数字孪生场景）。

论文的初步结果表明，通过扩展相关游戏数据的覆盖与组合，性能与泛化能力仍有提升空间，但这种增益高度依赖于训练经验的**领域构成**与目标环境的匹配度（参见第 2.3 节 $L_{\text{val}}(N, D, q)$ 的 scaling 关系）。

### 2. 分层推理与实时控制的协同架构
尽管 Gamer 通过稀疏推理在延迟与性能之间取得了平衡，但在需要深度战略思考的复杂环境中，单一的快速反应式策略仍可能存在瓶颈。一个值得探索的方向是构建**分层游戏智能体架构**：
- **System 2（审慎推理层）**：由更大规模的模型承担长程规划、高层策略制定与复杂逻辑推演；
- **System 1（反应执行层）**：由轻量级快速模型负责实时的感知-动作闭环与环境反馈响应。

此类架构需要解决两层模型之间的信息传递、决策同步与状态一致性维护问题，尤其是在长时程任务中保持高层规划对低层执行的持续有效指导。

### 3. 记忆机制的深化与结构化
当前的记忆压缩依赖于文本摘要 $r_t^{\text{mem}}$ 的生成与级联存储（见第 3.2 节式 (10)）。未来研究可探索：
- **结构化外部记忆**：超越文本摘要，引入可检索的符号化知识图谱、场景拓扑表示或对象级持久化状态；
- **自适应记忆保留策略**：根据任务相关性动态决定历史信息的遗忘与保留比率，而非基于时间顺序的 FIFO 淘汰；
- **跨任务记忆迁移**：研究不同游戏或任务之间记忆内容的可重用性，支持跨域技能的元学习。

### 4. 推理成本优化与边缘端部署
Streaming-vLLM 在 H200 等高阶 GPU 上实现了低延迟实时交互，但广泛部署仍受限于计算成本。进一步探索包括：
- **模型压缩技术**：如量化、剪枝与知识蒸馏，在保证策略性能的同时降低对硬件资源的需求；
- **更高效的推测解码与稀疏激活**：针对 MoE 架构优化专家路由与 FSM 引导解码的协同设计；
- **端侧推理与云边协同**：将部分感知与低频决策卸载至边缘设备，仅将复杂推理交由云端处理。

### 5. Scaling Laws 的深化与远距离泛化
GameScaling 研究（第 8.2 节）揭示了 CPT 在训练覆盖环境与行为相关环境上的可预测增益，但对于**远距离未见游戏**（distant unseen games），验证损失在早期界面适应后趋于饱和甚至上升，且拟合指数 $b \approx 0$。这提示：
- 需要更精细的跨领域迁移度量，以量化游戏机制、视觉风格与控制语义之间的分布距离；
- 探索超越单纯数据堆叠的迁移机制，如模块化控制原语学习、可组合技能库或跨游戏的环境动力学建模。

### 6. 极端稀疏奖励下的信用分配
TA-GRPO 通过时序折扣权重 $\tilde{d}_{g,m,t}$（第 4.2 节式 (12)）缓解了段内信用分配问题，但在奖励极度稀疏或延迟极长（如数小时量级的单一终局反馈）的场景中，在线学习的稳定性与样本效率仍面临挑战。未来可探索：
- 结合人类示范或离线数据的混合 RL 范式；
- 自动发现与验证中间里程碑的自动化课程生成方法；
- 基于对比学习的隐式价值估计，以补充环境可验证的稀疏信号。

### 7. 向物理世界与多智能体系统的迁移
论文指出，游戏轨迹训练为智能体学习物理与数字混合属性环境提供了可行路径。进一步的方向包括：
- **物理世界部署**：将基于屏幕-键鼠接口学习到的交互策略迁移至具身机器人，研究视觉-动作表征在物理域中的可迁移性；
- **多智能体协作与对抗**：当前框架聚焦单智能体任务，未来可扩展至多智能体场景，研究实时通信、角色分工与群体策略涌现。

## Q6: 总结一下论文的主要内容

这篇论文介绍了 **Gamer**，一个面向复杂交互环境长时程任务的通用视觉-语言-动作（VLA）基础模型。以下从研究背景、技术框架、核心创新与实验结论四个维度进行总结。

---

### 1. 研究背景与核心问题

多模态大语言模型（MLLMs）正从静态输入处理器向交互式智能体演进，但真实世界物理环境的试错成本高昂且难以控制。现代大型游戏结合了真实复杂度与严格的实验可控性，为开发通用 VLA 智能体提供了理想测试平台。然而，现有方法通常依赖游戏内部状态、定制动作空间或专用 API，泛化能力受限；同时，长时程任务要求智能体在数小时交互中管理记忆、规划与决策，而实时推理延迟会进一步放大控制误差并劣化在线强化学习（RL）的反馈质量。为此，论文致力于解决以下核心问题：

- 如何仅通过**原始屏幕像素**和**标准键盘鼠标接口**，实现对多样化游戏的非侵入式通用控制；
- 如何在**有限上下文窗口**下支持数小时级别的长时程任务执行与记忆保持；
- 如何构建**低延迟实时推理**基础设施，满足部署与在线训练的双重需求。

---

### 2. Gamer 总体框架

Gamer 采用端到端的自回归架构，以统一的屏幕到动作接口实现感知、记忆管理与多步推理的闭环。其训练与部署流程包含三个递进阶段：

- **持续预训练（CPT）**：在数万小时跨游戏键鼠交互轨迹上继续预训练，建立可迁移的控制先验；
- **监督微调（SFT）**：通过多层级指令数据（局部操作、中间子目标、完整任务）引入稀疏推理与跨上下文记忆；
- **时序感知 GRPO（TA-GRPO）**：利用环境可验证的反馈，对长时程轨迹片段进行在线策略优化。

配套提出 **Streaming-vLLM** 推理引擎，作为训练、评估与部署的共享后端，支持无界上下文、高并发实时交互与低延迟动作生成。

---

### 3. 核心技术创新

#### 3.1 统一设备级动作表示与去偏

Gamer 将跨游戏控制映射为统一的键鼠动作序列。每个 200 ms 观察间隔内，策略预测累积鼠标位移与六个 33 ms 按键块，实现 30 Hz 底层控制频率。为消除数据偏差，引入两项机制：

- **随机按键重映射**：在轨迹级别对可重绑定按键进行随机双射，迫使模型依据功能而非键位身份生成动作；
- **重复感知损失衰减**：对连续重复动作的监督施加指数衰减权重 $\omega_t = \gamma^{n_t-1}$（$\gamma=0.9$），将学习重点聚焦于行为转换。

#### 3.2 稀疏推理与记忆链接

SFT 阶段训练策略在三种输出模式间自适应切换：直接动作（$r_t = \emptyset$）、当前决策推理（$r_t^{\text{cur}}$）与记忆摘要（$r_t^{\text{mem}}$）。当历史交互即将超出上下文预算时，模型生成压缩摘要并更新长程记忆：
$$
\langle M_t^+, H_t^+ \rangle = \langle \bar{M}_t \oplus r_t^{\text{mem}}, H_t^{\text{keep}} \rangle
$$
这使得任务状态得以跨越上下文边界持久保存。

#### 3.3 时序感知的在线策略优化（TA-GRPO）

针对长交互超出上下文与稀疏奖励问题，TA-GRPO 将轨迹按记忆边界切分为有限片段，利用环境可验证结果计算组相对优势。通过时序折扣权重将段级优势分配至个体决策：
$$
\tilde{d}_{g,m,t} = \frac{\beta^{T_{g,m}-1-t}}{\frac{1}{T_{g,m}}\sum_{u=0}^{T_{g,m}-1} \beta^{T_{g,m}-1-u}}, \quad A_{g,m,t} = \tilde{d}_{g,m,t} A_{g,m}
$$
避免了完整轨迹拟合与游戏状态恢复的开销。

#### 3.4 Streaming-vLLM 实时推理引擎

- **状态流式上下文**：保留 KV 缓存，增量计算新追加 token，并在记忆压缩后通过增量 RoPE 相位刷新修正保留键值位置；
- **FSM 引导的推测解码**：利用有限状态机快速起草结构化 token，经 BF16 目标模型验证后提交，减少串行解码步数；
- **流式动作分发**：首个验证通过的动作块即刻发往客户端执行，后续块并行生成，将端到端延迟从约 1.3 秒降至 65 毫秒（20.1× 加速）。

---

### 4. 实验结果

论文从扩展规律、跨游戏控制、长时程任务、多样化小游戏、实时训练影响与推理效率六个方面展开评估：

- **CPT 扩展规律（GameScaling）**：120 个受控配置的 scaling 研究表明，模型性能不仅取决于数据量，更依赖于数据组成与目标分布的相关性。拟合公式 $L_{\text{val}}(N, D, q) = E + \frac{C_N}{N^a} + \frac{C_D q^\eta}{D^b} + \frac{C_q}{(q+\epsilon)^c}$ 准确刻画了这一依赖关系。
- **跨游戏实时控制**：在 MCU、ViZDoom、OmniGameArena、GameWorld 基准上，Gamer-CPT（8B Dense / 35B-A3B MoE）显著超越 GPT-5.6-Sol、Gemini、Claude 等通用多模态基线，且 MoE 模型因推理更快在实时模式下获得额外增益。
- **长时程支线任务**：在 Honkai: Star Rail 两个保留支线任务（30 与 55 个里程碑）上，Gamer-RL 的总体准确率分别达到 **80.0%** 与 **83.6%**，相比 SFT 提升 7.8 与 14.5 个百分点，验证了在线反馈对长时程执行的改进作用。
- **多样化小游戏泛化**：在 7 类 40 个小游戏上，Gamer-RL 的七类宏平均准确率达到 **49.7%**，相比 SFT（39.2%）提升 10.5 个百分点，表明在线优化可泛化至不同规则与交互模式。
- **实时交互对 RL 的关键作用**：对比实验表明，使用标准 vLLM 的低帧率（0.6-FPS）rollout 在多任务后期出现奖励崩溃，而 Streaming-vLLM 的实时推理实现了更早、更稳定的策略改进，证明低延迟是在线 RL 有效的必要前提。
- **推理引擎性能**：Streaming-vLLM 在 StreamingBench 与 OVO-Bench 上保持甚至提升了流式视频理解准确率，同时将查询延迟降低至 0.08–0.16 秒级别。

---

### 5. 结论

Gamer 证明，即使仅依赖重复的键盘鼠标轨迹，通过规模化数据、多级监督与稳定的在线学习算法，仍能实现复杂 3D 游戏中的长时程实时控制。其统一的非侵入式接口、稀疏推理与记忆机制、以及低延迟推理引擎，为开发能够跨越数字与物理世界的通用交互智能体提供了一条可行路径。论文进一步指出，未来工作可在更广阔的环境覆盖、分层推理架构、结构化外部记忆、边缘端成本优化以及向物理世界的迁移等方向上继续深化。
